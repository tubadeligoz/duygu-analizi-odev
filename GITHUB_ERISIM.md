# GitHub üzerinden erişim

Proje deposu: https://github.com/tubadeligoz/duygu-analizi-odev

Depo herkese açıktır. Dosyaları görmek ve indirmek için davet kabul etmek gerekmez.

## İndirme

GitHub sayfasında **Code → Download ZIP** seçeneğini kullanabilir veya Git ile indirebilirsiniz:

```powershell
git clone https://github.com/tubadeligoz/duygu-analizi-odev.git
cd duygu-analizi-odev
```

README üzerinde grafikler, sonuçlar, gerçek hata örnekleri ve kaynaklar doğrudan görüntülenir. Hazırlanan teslim ZIP'i bu depoya eklenmemiştir.

## Önce açılacak dosyalar

- `README.md`: kurulum, çalıştırma ve gerçek sonuçlar.
- `deliverables/Proje_Raporu.docx`: Türkçe rapor.
- `deliverables/SUNUM_VE_KONUSMA_TASLAGI.md`: üç kişilik sunum akışı.
- `deliverables/TESLIM_KONTROL_LISTESI.md`: grup tarafından tamamlanacak işler.
- `deliverables/comparison.csv`: altı deneyin karşılaştırması.

Kodlar, sabit veri bölümleri, model tahminleri ve değerlendirmeler paylaşılmıştır. Büyük BERT ağırlıkları, model önbelleği ve geçici dosyalar depoya dahil edilmemiştir; modeller README'deki sabit sürümlerle yeniden eğitilebilir.

Grup bilgileri, bağımsız insan hata incelemesi, video kaydı ve gerçek teslim henüz tamamlanmış sayılmaz.
